# Aghaaz Labs (Learn • Build • Grow) 🚀

A modern, high-converting tech-ed course platform website for **Aghaaz Labs**, inspired by high-tier developer academies like Sheryians Coding School, Frontend Masters, and NeetCode.

---

## 🌟 Features

- **Flyer-Inspired Design System**: Off-white slate background with a graph paper blueprint grid pattern, Electric Indigo & Sky Cyan palette, and handwritten sketch slogan annotations ("Same Course. Bigger Vision.", "Small Steps, Big Dreams", "Let's Build Your Future Together").
- **Interactive Code Terminal IDE**: Live code preview sandbox supporting C++, Python, and JavaScript logic simulation for LeetCode #1 Two Sum.
- **Live Demo Class Countdown**: Real-time ticking countdown timer targeting **THIS SUNDAY | 08:30 PM PKT**.
- **Sheryians-Style Course Grid**:
  - **Track 1 (Active)**: *Programming & Data Structures & Algorithms (DSA)* (Live batch, 60+ Hours, 150+ Problems, Hackathons, Discord/WhatsApp clearance).
  - **Track 2 (Upcoming)**: *Modern Web Development & Agentic AI* (Full-stack architectures, vector DBs, LangChain, and autonomous LLM agents).
- **5-Module Detailed Curriculum Accordion**: Complete syllabus with problem counts, memory models, and live C++ code snippets.
- **Student Roadmap Visualizer**: 3-step career pathway (DSA ➔ Full-Stack Web Dev ➔ Autonomous Agentic AI).
- **Developer Resources & Cheat Sheets**: Interactive preview and download drawer for C++ DSA, Big-O Complexity, Pointers, and LeetCode patterns.
- **Lead Capture & WhatsApp Direct Booking**: Registration modal with input validation, confetti animations, and direct pre-filled WhatsApp link generation to `+92 335 6662958`.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Plus Jakarta Sans, JetBrains Mono, Caveat (Google Fonts)
- **Effects**: Canvas Confetti
